# HSE CS Open Code Contest

The Open Code Contest encourages students and PhD candidates at HSE University’s Faculty of Computer Science to develop and publish open-source software. Participants can submit software from coursework, theses, or independent projects, either individually or as a team. [Official contest page](https://cs.hse.ru/opensource/open_source)

## 2026 winners

- [**UniversalToolchain**](https://github.com/Misha1302/UniversalToolchain) — a modular compiler and runtime framework behind Wist, which validates numeric formulas and compiles them into typed .NET delegates. Winner: Mikhail Razakov.
- [**Online GCS**](https://github.com/qrvmil/GCS) — a motion planner for robotic manipulators that adds collision-free regions to a graph of convex sets as needed. Winner: Milana Krivova.
- [**Hyppopipe**](https://github.com/hse-cs/hyppopipe) — a Python framework for building medical imaging pipelines with configurable steps for image processing, classification, and segmentation. Winner: Georgy Lanin.

## 2025 winners

- [**algolymp**](https://github.com/Gornak40/algolymp) — command-line tools for running Ejudge contests and managing Polygon problem packages. Winner: Alexander Gorbunov.
- [**SuperCFG**](https://github.com/enaix/SuperCFG) — a header-only C++20 parser generator that builds grammar structures at compile time. Winner: Andrey Savchuk.
- [**PM-IDE Workspace**](https://github.com/PM-IDE/workspace) — tools for capturing .NET execution events and mining software processes from the resulting logs. Winner: Evgeny Stepanov.
