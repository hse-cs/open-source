HSE CS Open Source

A collection of open-source projects and resources created by HSE CS staff and students, including research code, courses, and other educational and technical resources.

⭐ If you find a project useful, please consider starring this repository and the projects listed below. It helps make these resources more visible and supports the people who created them.

Contributing

Have an open-source project or resource created at HSE CS?

Simply open an issue with a link to the project and, optionally, its associated paper. A paper is not required — we will add the project to the collection ourselves.

You can also submit a pull request to add or update an entry. See the contribution guidelines for the entry format and review checklist.
